## About this assignment

This repository contains my solutions to all 20 questions of the Python Loops & Functions assignment. The questions build up in four stages:

- **Q1-9:** `for` loops, nested loops, lists, strings and dictionaries
- **Q10-13:** `while` loops for menu-driven and repeat-until programs
- **Q14-19:** functions that return values, plus small applications built from several functions
- **Q20:** a final project combining functions, `for` loops and `while` loops

Each file starts with a comment explaining why I chose a `for` loop, a `while` loop or a function for that problem.

## Setup and run instructions

1. Install Python 3.8 or newer. Check with:
   ```
   python --version
   ```
2. Clone the repository:
   ```
   git clone [your-repo-url]
   cd super30-python-loops-functions-assignment
   ```
3. Run any program:
   ```
   python 1.NumberAnalyser.py
   ```
   On some systems use `python3` instead of `python`.

No external libraries are needed. Only the built-in `random` module is used (Q12).

## What I learned

- Use `for` when the number of repeats is known (a range, a list, a string).
- Use `while` when the program repeats until a condition changes (Exit, correct guess, attempts used up).
- Use functions for logic that is reusable, and make them `return` values instead of only printing.
